### 1.3 的关键结论：上海产物逐字节不变

15 个脚本改成 `load_city()` + `Paths` 之后，上海 11 份产物（含 geoJSON、两份 index、三份 md）与改造前**逐字节一致**，只差 `generated_at`。
两次踩坑记在 ADR §9.4：`05` 会覆盖 `docs/conflicts.md` 的人工段；`km_per_deg` 从 95.3 改 95.2 会让上海面积整体 −0.1%。

### 1.4 的关键结论：广州真跑抓出 6 个 bug

广州不是上海，真跑一次暴露了 6 处「上海能用、多城不能用」的写法（详见 ADR §10）：

1. `02` 的省份清单与输出路径写死；
2. `04` 缺 `import os`；
3. `04/05` 把全局审计文件当自家文件写 → 覆盖上海基线（543 条 / 287 条标 removed）；
4. `06/07/08` 读全局 index → 广州映射表 0 行；
5. `06` 导出整个省 → 广州 256 行（含香港 54、深圳 46）；
6. `line_id_prefix` 被加了第二个 `@property`。

**同省跨市**是这一轮最有价值的发现：`05` 原先只在「跨省」时记 `conflicts`，佛山 22 站里有 7 站会退回 `CITY_DEFAULT`。
修法（ADR §12）：触发条件改为 `len(distinct_cities) > 1 and len(distinct_provs) <= 1 and CFG.city in distinct_cities`。
第三个条件不能写成 `city == CFG.city`——广佛线佛山占 15/25，主城市是佛山市，会被误排除。

## 五之二、成都 / 合肥 P1a-5.4 记录（2026-11-05）

| 城市 | 13 校验 | 确定性（--rerun） | 备注 |
| --- | --- | --- | --- |
| 成都 | 8/8 通过 | 差异 0 份 | 454 段 / 364 站 / 16 线 / 4 换乘 |
| 合肥 | 8/8 通过 | 差异 0 份 | 207 段 / 195 站 / 8 线 / 0 换乘 |

两次踩坑：

1. **产物陈旧会让第 8 项假失败**：`--rerun` 比的是「磁盘现状」与「重跑结果」。
   某个城若只单独跑过 `12`（没跑 `08`），`lines.json` 就带着上一轮的 `colour`，
   与 `08→12` 全链路结果不同 → 第 8 项报差异。第一次跑出现差异时，
   **再跑一次 `--rerun` 即可确认**（一次重跑会把产物刷成全链路结果）。
2. **`colour_osm` 会自我污染**：`12` 原本写 `colour_osm = colour`，若单独重跑 `12`
   就会把上一轮 override 后的颜色写回 `colour_osm`，丢失「OSM 原值」。
   已改为 `if colour_source == "osm" or not colour_osm: colour_osm = colour`，
   并加注释：`12` 应在 `08` 之后运行（`run_city` / `--rerun` 都满足）。

6.4 之后的两条新状态：

3. **三城底图已补，体积 7.91 MB → 上限已抬到 10 MB（ADR 0005）**：8 MB 是 P0 单城时定的口径，多城后它衡量的是「四城全量未压缩总和」，而首屏只加载当前城那一份（gzip ≈300–500 KB）。抬到 10 MB 的完整理由与四个备选方案见 `docs/decisions/0005-size-budget.md`。
4. **首屏贴合偏松，且这是几何结果不是 bug**：`fitBounds` 受较短边约束——广州纬度跨 0.87°，在 1256×808 窗口里必然被高度卡住，左右留白是「南沙到花都全都要进画面」的代价。本轮只做了 padding 72/96 → 56/56 的收紧（四城各 +0.12 档：广州 8.90→9.02、成都 9.44→9.56、合肥 9.99→10.11、上海 9.59→9.71）。**再想贴合只能裁掉南北端站点，P1a 不做**；若以后要「市区优先」的观感，应另做「按站点密度加权取景」，而不是继续压 padding。

6.6 之后的一条新状态：

5. **「推送成功」不再等于「线上可用」**：Pages 重建有 30–60 s 延迟，第 1、2 轮冒烟必然 404。脚本按五轮轮询把它和「真的 404」区分开——本轮第 3 轮（约 35 s）通过。另记一次外部故障：2026-11-11 08:19–08:34 GitHub `:443` 整段不通（`Test-NetConnection` 连续 6 次 False，与 AGENTS §11 记的域名级间歇中断一致），部署重试 5 轮（21 s 连接超时 + 15/30/60/120 s 退避）全部失败后退出；网络恢复后 `--no-build` 重跑第 1 次即成功。**结论：撞上断网不要改脚本、不要加大重试，等 TCP 通了再跑一次。**
