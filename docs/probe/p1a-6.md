## 六、风险

1. **广州 1.25 MB 的 `segment.geojson`** 是四城最大单文件；懒加载后首屏仍可接受（gzip 约 200 KB），但切换时会有一次明显下载。
2. **非上海底图需要新脚本**：复用 `03_extract_basemap` 的 L5 面拼装逻辑，改成按 `cities/<code>.json` 的 bbox 取「市界 + 有名字的主河道」；广州若要海面还需按 `14_extract_sea` 拼珠江口 coastline。
3. **`/` 与 `/sh/` 内容重复**：静态导出下两者都要生成，注意 canonical 指向 `/`，避免重复收录。
4. **构建时间**：四页 + 四城数据，预计 `next build` 从 5 s 增到 15–20 s，仍在可接受范围。
