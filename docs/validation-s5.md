## 5. 已知边界（不修，属设计取舍）

1. **没有键盘上下选择**：只支持 `Enter` 选第一条。S5 收敛到「极简检索」时明确砍掉，理由是与地图交互抢焦点、收益低于成本。
2. **没有 URL 状态**：刷新后回到默认视角。
3. **没有线路筛选条**：线路结果只做「框视野」，不做多选高亮。
4. **单城**：`AGENTS.md` §12 的「按城市检索」在 P0 只有上海一城时等于空操作，已加脚注说明；多城切换属 P1。
5. **同分平手**：`一大会址` 两站分数完全一致，靠「名字短者优先」决胜，属规则而非 bug。
6. **首字母同码**：`lyl` → 龙阳路 / 龙耀路，`ljz` → 陆家嘴两站，都靠结果行色点与站名后缀区分。
